# Waste Type Classification using Machine Learning

A beginner-friendly terminal application that uses a trained Artificial Neural
Network (ANN) to predict whether waste is Organic, Plastic, Paper, Metal, or
Glass. A Random Forest model is also trained so the two approaches can be
compared.

## Dataset notice

The project includes `dataset.csv`, but it is a **clearly labelled synthetic
dataset** generated by `train_model.py` for demonstration. It is not a
real-world waste dataset. If a real public CSV is obtained later, replace
`dataset.csv` and keep the same column names.

## Required columns

- `biodegradable`: 1 or 0
- `recyclable`: 1 or 0
- `weight_grams`: numeric weight
- `material_composition`: material name
- `waste_category`: Organic, Plastic, Paper, Metal, or Glass

## Simple project explanation

This project has two different waste classifiers:

- **ANN for waste details:** the user enters whether an item is biodegradable
  and recyclable, its weight, and its material. The trained ANN predicts
  Organic, Plastic, Paper, Metal, or Glass.
- **CNN for waste images:** the user uploads a photo. The trained CNN predicts
  Cardboard, Glass, Metal, Paper, Plastic, or Trash.
- **Random Forest:** is trained only for comparison with the ANN.

The main flow is:

```text
Waste details or image
        |
        v
Cleaning and preprocessing
        |
        v
ANN or CNN model
        |
        v
Waste category, confidence, and disposal guidance
```

The trained files are reused, so normal use does not require retraining:

- `waste_model.pkl` - trained ANN and Random Forest
- `waste_image_cnn.keras` - trained CNN
- `image_classes.npy` - CNN category names

## What training does

`train_model.py`:

- loads and cleans `dataset.csv`
- removes invalid or duplicate rows
- performs an 80:20 train-test split
- preprocesses categorical and numeric features
- trains an Artificial Neural Network using scikit-learn's
  `MLPClassifier.fit()`
- uses ReLU hidden layers with 32 and 16 neurons and the Adam optimizer
- uses early stopping to stop training when validation loss stops improving
- trains a Random Forest comparison model
- predicts test rows with `model.predict()`
- reports ANN and Random Forest accuracy, a confusion matrix, and a
  classification report
- saves `waste_model.pkl`
- saves `confusion_matrix.png`
- saves `ann_training_loss.png`

The terminal interface is in `main.py`. Prediction is performed by the trained
ANN in `predict.py`; no results are hardcoded.

## ANN workflow

```text
User features
     ↓
One-hot encode material + scale weight
     ↓
Input layer → Dense(32, ReLU) → Dense(16, ReLU) → Output layer
     ↓
Waste category
```

This uses a genuine feed-forward neural network, not a pretrained model or an
external AI API. `MLPClassifier` is used instead of TensorFlow so the project
stays lightweight and easy to install for beginners.

### CNN image classification

The CNN is a separate deep-learning model because it learns visual patterns
from pixels, while the ANN learns patterns from structured numerical details.
This project uses the public **TrashNet** dataset by Gary Thung and Mindy
Yang. It contains 2,527 images in six classes: glass, paper, cardboard,
plastic, metal, and trash.

Source and citation:

- https://github.com/garythung/trashnet
- https://huggingface.co/datasets/garythung/trashnet

Download and prepare it automatically:

```powershell
python download_image_dataset.py
```

The prepared dataset has this structure:

```text
image_dataset/
  Cardboard/
  Glass/
  Metal/
  Paper/
  Plastic/
  Trash/
```

Install the optional CNN dependencies, then train and predict:

```powershell
python -m pip install -r requirements-image.txt
python image_cnn.py --train
python image_cnn.py --image path\to\waste.jpg
```

The image model predicts the six TrashNet labels. `Organic` is a label in the
structured numerical dataset, but it is not an image class in TrashNet. The
project does not fabricate image results: the CNN must be trained on the
downloaded images before image prediction is available.
